# 安装与使用

## 下载
从 [GitHub Releases](https://github.com/newDaly/Zuoyou-Project-card/releases/latest) 下载 `project-retrospective-card-v版本.zip`，不要误用只有源码目录外壳的自动 Source code 压缩包。ZIP 内顶层为 `project-retrospective-card/`，其下直接包含 SKILL.md、assets、references、scripts、agents。私有仓库需账号具有访问权限。

## WorkBuddy
1. 打开桌面客户端的“技能”页面，选择“添加技能→上传技能”。
2. 选择下载的完整技能包，按界面完成导入并启用。
3. 确认模板、规范与 scripts 子目录均随包导入；若当前版本仅接受其他导入形式，按客户端提示解压并导入完整文件夹，不只上传 SKILL.md。
4. 提供目标文件夹访问权限，输入下面的通用调用语句。
官方说明：[技能](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)。不同客户端版本的入口名称可能变化，不依赖未经确认的隐藏安装目录。

## 豆包工作
1. 进入“技能·连接器·伙伴”，找到技能管理中的本地导入/自定义技能入口。
2. 按客户端接受的格式导入 ZIP 或解压后的完整技能目录。官方说明确认支持本地技能文件导入，但具体扩展名、入口与桌面文件权限以当前版本为准，不承诺所有版本直接接受此 ZIP。
3. 若仅可创建自定义技能，将 SKILL.md 作为执行指令，并将 assets 模板、references 规范及 scripts 作为随附资源一起导入；不能附带资源或运行脚本的版本，需先换用具备等效文件工具的执行环境。
4. 在任务中选择本技能并提供可访问的目标资料文件夹；仅有云端运行能力时，先上传资料副本，不填写其无法访问的电脑路径。
官方介绍：[豆包工作主要功能](https://www.feishu.cn/content/article/7677519271848610746)。

## Codex
将解压后的完整 `project-retrospective-card` 文件夹放入本机 `~/.agents/skills/`；Windows 通常为 `%USERPROFILE%\.agents\skills\`。若已有同名目录，先备份后替换。重新载入 Agent 后调用 `$project-retrospective-card`。组织管理版或不同宿主提供技能导入界面时，按该环境说明导入，不将本机路径当成所有 Codex 环境的通用入口。

官方参考：[Build skills](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。旧版本或特殊宿主若指定 `~/.codex/skills/`，以宿主实际技能目录为准。

## 依赖
脚本需要 Python 3.10+。优先使用宿主已有工具；需要脚本时在选定的 Python 环境运行：
```bash
python -m pip install -r "技能安装目录/scripts/requirements.txt"
```
依赖包括 python-docx、python-pptx、openpyxl、pypdf、msoffcrypto-tool。最后一项用于 Office 加密检测；缺失时必须报告“检测未完成”。图片和扫描页需 Agent 视觉工具或本地 OCR。旧版 Office 等格式可能需要本地转换工具。安装成功不代表全部格式均可解析。

## 调用
```text
使用项目复盘知识卡技能，读取 D:/项目资料/某项目。
先扫描所有文件并提醒其他格式、压缩包和加密文档。
按模板生成知识卡，最终只保留知识卡 Markdown，清理本次过程文件。
```
正常流程：先扫描提醒→阅读与补读→编写并核验→清理临时工作区→只交付知识卡。来源和阅读边界保留在卡内，不再单独输出核查文件。未授权时不解压、不破解，读取失败不误判为加密。

## 推荐 Obsidian 阅读与编辑
推荐使用 [Obsidian](https://obsidian.md/) 管理项目知识卡：Markdown 是其主要笔记格式，可以直接阅读和修改，不需要转换为专有格式。
1. 已有知识库：把生成的 `.md` 文件放入现有仓库文件夹。
2. 新建知识库：在 Obsidian 选择打开本地文件夹作为仓库，选择“知识卡输出”或公司的知识卡总目录。
3. 使用属性查看年度、客户、行业和省市，使用 tags 和搜索聚合知识卡，使用 Markdown 链接定位资料。
4. 移动知识卡后，检查原有相对路径是否仍可定位；必要时调整路径，不将临时目录作为来源。
Obsidian 只承担阅读和编辑，不负责执行本 Skill；可继续使用其他 Markdown 编辑器，不强制安装或开通同步。
官方参考：[导入 Markdown](https://obsidian.md/help/import/markdown)。
