# 本地一键执行

## 首次使用的前置准备
尚未部署的同事先按 [MinerU前置部署](MinerU前置部署.md) 完成环境、模型与小样本验收，再安装完整Skill及脚本依赖。已有部署直接继续，不重装。

## 用户只需发出一次任务
```text
使用项目复盘知识卡技能，处理 D:/项目资料/某项目。
我已在 D:/MinerU 部署 MinerU，请自动完成扫描提醒、本地解析、全文合并、按规范生成知识卡和清理，最后保留两份Markdown。
```
无需手动逐次执行解析、合并、读取、写卡、清理命令。Agent负责这些步骤的衔接；异常阻断才询问。

## 自动识别本地部署
统一入口按以下顺序查找MinerU：
1. `--mineru-command` 指定的完整可执行文件路径。
2. 环境变量 `PROJECT_CARD_MINERU_COMMAND`。
3. Windows常见部署路径 `D:\MinerU\.venv\Scripts\mineru-kit.exe`。
4. PATH中的 `mineru-kit`。

你的既有部署可以直接命中第3项，不需要重新安装MinerU，也不需要重新下载模型。其他同事可在其终端中持久配置自己的环境变量，或让Agent在调用参数中使用其实际安装路径。不要为找工具全盘搜索。
WebUI不是依赖：解析走本地CLI，不占用或检查7860端口，不需双击启动WebUI。默认串行解析，适合单卡8GB显存；并发会增加内存和显存占用，仅在验证后调整 `--workers`。

## Agent内部自动执行
以本Skill实际安装目录作为命令前缀，不假定当前工作目录已在Skill内。选用能运行本Skill依赖的Python；Windows可使用已有 `D:/MinerU/.venv/Scripts/python.exe`，但需确认本Skill扫描/校验依赖已安装。缺依赖时按宿主规则一次性安装 `scripts/requirements.txt`，不重装MinerU。

先运行扫描入口并把提醒显示给用户：
```bash
python scripts/run_project.py --source "项目文件夹" --scan-only
```
随后无需等待普通提醒的确认，自动运行解析合并：
```bash
python scripts/run_project.py --source "项目文件夹"
```
默认定位本地MinerU并完成逐文件解析和合并，返回JSON中的 `project_markdown`、`knowledge_card`、`workspace`。若未找到部署，向使用者确认可执行文件位置；显式路径示例：
```bash
python scripts/run_project.py --source "项目文件夹" --mineru-command "D:/MinerU/.venv/Scripts/mineru-kit.exe"
```
Agent接着完整读取project_markdown，按模板、复盘规范及 [知识卡质量规则](知识卡质量规则.md) 精简写入knowledge_card，并填写返回的review_file（card_review.json）的阅读范围、关键证据、计算和语义复核。普通Python脚本仅承担确定性转换/合并，不调用LLM；用户一次调用Skill后由Agent继续完成写卡，不能把合并成功当作整个任务结束。
生成并审核卡片后，Agent自动完成收尾：
```bash
python scripts/run_project.py --finish "返回的workspace"
```
收尾要求两份文件存在、非符号链接、总文档哈希未变，并检查知识卡结构、篇幅、引用映射、文件统计、已登记计算及临时复核记录。review_file随过程文件清理，不作为正式交付。失败则修正后重试。脚本校验结构，业务正确性由Agent依据全文审核。

## 输出及异常
最终默认保存到目标文件夹的 `知识卡输出`，同名历史成果不覆盖：
- `项目名称_项目内容.md`
- `项目名称_项目知识卡.md`
其他本次过程文件清理，源资料/历史结果/模型缓存/部署保留。自定义 `--output-dir` 应位于源目录外，以免后续运行重复摄入输出。
压缩包、加密文件、解析失败默认阻止合并；已明确同意不完整草稿才允许 `--allow-partial`。仅加密探测未知时提醒，不假定加密或无加密。未转换原因写入总文档及卡片的阅读边界，无法解析不靠Agent直接读原始Office替代。
Agent会在输出后提醒使用者确认客户信息、项目事实、成果状态和待核实内容。两份Markdown均适合Obsidian阅读编辑。

## 本地与隐私边界
默认统一入口只调用本地CLI，不需在线Token，不启动WebUI、不调用本Skill的在线API。它会清除子进程继承的MINERU_API_URL与MINERU_API_KEY，但本地MinerU的模型下载或自行配置的外部后处理仍取决于实际部署。已部署环境应确认模型就绪且没有不需要的远程服务，不把“本地命令”承诺成所有第三方组件绝对断网。

## 测试边界
可以用样本验证自动查找、解析调度、全文合并、Agent写卡衔接、格式检查和安全清理。本Skill开发环境无法访问使用者D盘；模拟调用测试通过不能宣称已对其Windows MinerU实机验收。
